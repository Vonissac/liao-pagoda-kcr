# Prompt Engineering Materials

This directory contains the complete prompt and grammar materials used for the three staged LPSL reconstruction configurations described in the manuscript.

- [Section A grammar](section_A_grammar.md) · [Section A prompt](section_A_prompt.txt)
- [Section B grammar](section_B_grammar.md) · [Section B prompt](section_B_prompt.txt)
- [Section C grammar](section_C_grammar.md) · [Section C prompt](section_C_prompt.txt)

The files are provided as separate, citable plain-text/Markdown documents for reproducibility and peer review. Placeholders such as `{grammar}`, `{kg_knowledge}`, and `{single_kg_prototype}` are runtime insertion points defined by the corresponding experimental configuration.
